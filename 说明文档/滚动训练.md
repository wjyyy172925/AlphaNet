## `start` 和 `end` 的含义

滚动训练代码中：

```python
start = sum(target_dates < unique_dates[i])
end = sum(target_dates < unique_dates[i + 1200 + 300 + 126])
```

这两步的作用是：把 `unique_dates` 中的日期位置转换成
`target_dates` 中可以直接用于切片的行索引。

其中：

```text
训练集: 1200 天
验证集: 300 天
测试集: 126 天
总窗口: 1626 天
```

### 示例

假设日期如下：

```text
unique_dates =
[1月1日, 1月2日, 1月3日, 1月4日, 1月5日, 1月6日, 1月7日]

target_dates =
[1月1日, 1月1日, 1月2日, 1月3日, 1月3日,
 1月4日, 1月5日, 1月5日, 1月6日, 1月7日]
```

假设当前窗口起点为：

```python
i = 2
```

此时：

```python
unique_dates[i] = 1月3日
```

计算起点：

```python
target_dates < 1月3日
```

结果为：

```text
[True, True, True, False, False, False, False, False, False, False]
```

`True` 的数量为 3，因此：

```python
start = 3
```

这表示 `target_dates` 从第 3 行开始进入当前训练窗口。

为了便于演示，假设完整窗口长度为 4 天，则结束日期位置为：

```python
i + 4 = 6
unique_dates[6] = 1月7日
```

计算结束位置：

```python
target_dates < 1月7日
```

共有 9 条数据早于 1 月 7 日，因此：

```python
end = 9
```

当前完整窗口对应：

```python
target_dates[start:end]
```

也就是：

```text
target_dates[3:9]
= [1月3日, 1月3日, 1月4日, 1月5日, 1月5日, 1月6日]
```

注意，`end` 是右开边界，因此 1 月 7 日不会被包含。

### 后续划分

在真实代码中，完整窗口长度为 1626 天，因此可以按下面方式划分：

```python
train_start = start
train_end = start + 1200

valid_start = train_end
valid_end = valid_start + 300

test_start = valid_end
test_end = end
```

对应的数据切片为：

```python
train_data = data[train_start:train_end]
valid_data = data[valid_start:valid_end]
test_data = data[test_start:test_end]
```

之所以不能直接写成 `start = i`、`end = i + 1626`，是因为：

```text
unique_dates: 每个日期只出现一次
target_dates: 同一天可能有多只股票或多条样本
```

因此必须通过日期比较，找到日期在 `target_dates` 中对应的真实行索引。
