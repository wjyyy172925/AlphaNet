# AlphaNet-v1 模型结构

对应 `models.py` 中的 `AlphaNet` 类（第 166-266 行）。

```text
Input X [B, n, T]
|
|- 特征提取分支 1: ts_corr(d, stride)        -> [B, h, w] -> BN(h) -> Flatten
|- 特征提取分支 2: ts_cov(d, stride)         -> [B, h, w] -> BN(h) -> Flatten
|- 特征提取分支 3: ts_stddev(d, stride)      -> [B, n, w] -> BN(n) -> Flatten
|- 特征提取分支 4: ts_zscore(d, stride)      -> [B, n, w] -> BN(n) -> Flatten
|- 特征提取分支 5: ts_return(d, stride)      -> [B, n, w] -> BN(n) -> Flatten
|- 特征提取分支 6: ts_decaylinear(d, stride) -> [B, n, w] -> BN(n) -> Flatten
`- 特征提取分支 7: AvgPool1d(d, stride)      -> [B, n, w] -> BN(n) -> Flatten

同时，每个分支还会再做 3 种池化：

    AvgPool1d(d_pool, s_pool) -> BN -> Flatten
    MaxPool1d(d_pool, s_pool) -> BN -> Flatten
    MinPool1d(d_pool, s_pool) -> BN -> Flatten

拼接方式：

    f1 = concat(7 个原始特征分支)
    f2 = concat(7 个分支的 3 种池化特征)
    features = concat(f1, f2)

后续网络：

    features
      -> Linear(n_in, 30)
      -> ReLU
      -> Dropout(0.5)
      -> Linear(30, 1)
      -> Output [B, 1]
```

其中：

```text
h = n * (n - 1) / 2
```

默认参数为 `n=9`，因此：

```text
h = 36
n_in = 702
```

## AlphaNet-v1 `forward` 函数解读

### 1. 输入和符号定义

```text
X: [B, n, T]
```

其中：

```text
B: batch size
n: 输入特征数量
T: 时间序列长度
h: 两两特征组合数量，h = n * (n - 1) / 2
w: 时间窗口数量，w = floor((T - d) / stride) + 1
p: 池化后的时间窗口数量，p = floor((w - d_pool) / s_pool) + 1
```

默认情况下：

```text
d = 10
stride = 10
d_pool = 3
s_pool = 3
n = 9
h = 36
```

### 2. 初始化特征列表

```python
features_fe, features_p, i = [], [], 0
```

含义：

```text
features_fe: 保存 7 个特征提取分支得到的原始特征
features_p:  保存每个分支经过平均池化、最大池化、最小池化后的特征
i:           记录当前使用到的池化 BatchNorm 层索引
```

### 3. 特征提取和第一组 BatchNorm

代码对 `feature_extractors` 和 `batch_norms1` 逐一循环：

```python
for extractor, batch_norm in zip(self.feature_extractors,
                                 self.batch_norms1):
    x = extractor(X)
    x = batch_norm(x)
```

7 个分支的输出如下：

```text
1. ts_corr(X)
   [B, n, T] -> [B, h, w]
   计算 h 对特征组合在每个时间窗口内的相关系数

2. ts_cov(X)
   [B, n, T] -> [B, h, w]
   计算 h 对特征组合在每个时间窗口内的协方差

3. ts_stddev(X)
   [B, n, T] -> [B, n, w]
   计算每个特征在每个时间窗口内的标准差

4. ts_zscore(X)
   [B, n, T] -> [B, n, w]
   按当前代码实际计算的是“窗口均值 / 窗口标准差”

5. ts_return(X)
   [B, n, T] -> [B, n, w]
   计算窗口末值相对于窗口首值的收益率

6. ts_decaylinear(X)
   [B, n, T] -> [B, n, w]
   使用线性递减权重计算窗口内的加权平均值

7. AvgPool1d(d, stride)(X)
   [B, n, T] -> [B, n, w]
   计算每个特征在时间窗口内的平均值
```

每个分支后接 BatchNorm：

```text
[B, C, w] -> BatchNorm1d(C) -> [B, C, w]
```

其中 `C` 为 `h` 或 `n`，BatchNorm 不改变张量维度。

### 4. 保存原始特征并展平

```python
features_fe.append(x.flatten(start_dim=1))
```

`flatten(start_dim=1)` 保留 batch 维度，将通道维和时间维合并：

```text
[B, C, w] -> [B, C * w]
```

因此：

```text
ts_corr、ts_cov:
    [B, h, w] -> [B, h * w]

其余 5 个分支:
    [B, n, w] -> [B, n * w]
```

循环结束后，`features_fe` 中一共有 7 个展平后的原始特征。

### 5. 三种池化分支

注意：这里的池化都是沿时间维度进行的

每个特征分支 `x` 都会经过三种池化：

```python
x_avg = self.batch_norms2[i](self.avg_pool(x))
x_max = self.batch_norms2[i+1](self.max_pool(x))
x_min = self.batch_norms2[i+2](-self.max_pool(-x))
```

维度变化为：

```text
x:       [B, C, w]
平均池化: [B, C, w] -> [B, C, p] -> BatchNorm -> [B, C, p]
最大池化: [B, C, w] -> [B, C, p] -> BatchNorm -> [B, C, p]
最小池化: [B, C, w] -> [B, C, p] -> BatchNorm -> [B, C, p]
```

其中最小池化通过数学等价关系实现：

```text
min(x) = -max(-x)
```

然后将三种池化结果分别展平：

```python
features_p.append(x_avg.flatten(start_dim=1))
features_p.append(x_max.flatten(start_dim=1))
features_p.append(x_min.flatten(start_dim=1))
```

维度变化为：

```text
[B, C, p] -> [B, C * p]
```

每个原始特征分支产生 3 个池化特征，7 个分支一共得到 21 个池化特征。

### 6. 特征拼接

```python
f1 = torch.cat(features_fe, dim=1)
f2 = torch.cat(features_p, dim=1)
features = torch.cat([f1, f2], dim=1)
```

原始特征拼接：

```text
f1: [B, w * (2h + 5n)]
```

池化特征拼接：

```text
f2: [B, 3p * (2h + 5n)]
```

最终拼接：

```text
features: [B, (w + 3p) * (2h + 5n)]
```

### 7. 默认配置下的维度变化

当 `n=9`、`h=36`，并且输入时间长度使得 `w=3`、`p=1` 时：

```text
2h + 5n = 2 * 36 + 5 * 9 = 117
```

原始特征：

```text
f1: [B, 3 * 117] = [B, 351]
```

池化特征：

```text
f2: [B, 3 * 1 * 117] = [B, 351]
```

拼接后：

```text
features: [B, 351 + 351] = [B, 702]
```

这与代码中的定义一致：

```python
self.linear_layer = nn.Linear(702, 30)
```

### 8. 全连接输出部分

```python
features = self.linear_layer(features)
features = self.relu(features)
features = self.dropout(features)
output = self.output_layer(features)
```

维度变化为：

```text
[B, 702]
    -> Linear(702, 30)
[B, 30]
    -> ReLU
[B, 30]
    -> Dropout(p=0.5)
[B, 30]
    -> Linear(30, 1)
[B, 1]
```

最终 `forward` 返回一个 batch 内每个样本对应的单一预测值：

```text
output: [B, 1]
```

注意：`linear_layer` 的输入维度由代码固定为 `n_in=702`。因此实际输入时间长度必须使得：

```text
(w + 3p) * (2h + 5n) = 702
```

否则展平拼接后的特征维度可能与 `Linear(702, 30)` 不匹配。

# AlphaNet-v2 模型结构

对应 `models.py` 中的 `AlphaNet_v2` 类（第 273-353 行）。

```text
Input X [B, n, T]
|
|- 特征提取分支 1: ts_corr(d, stride)        -> [B, h, w] -> BN(h)
|- 特征提取分支 2: ts_cov(d, stride)         -> [B, h, w] -> BN(h)
|- 特征提取分支 3: ts_stddev(d, stride)      -> [B, n, w] -> BN(n)
|- 特征提取分支 4: ts_zscore(d, stride)      -> [B, n, w] -> BN(n)
|- 特征提取分支 5: ts_return(d, stride)      -> [B, n, w] -> BN(n)
`- 特征提取分支 6: ts_decaylinear(d, stride) -> [B, n, w] -> BN(n)

特征拼接：

    concat(dim=1)
    [B, h, w] + [B, h, w] + 4 * [B, n, w]
    -> [B, n_in, w]

时序建模与输出：

    [B, n_in, w]
      -> Transpose(1, 2)
      -> [B, w, n_in]
      -> LSTM(input_size=n_in, hidden_size=30, num_layers=1)
      -> [B, w, 30]
      -> Transpose(1, 2)
      -> BatchNorm1d(30)
      -> Transpose(1, 2)
      -> [B, w, 30]
      -> 取最后一个时间步
      -> [B, 30]
      -> Linear(30, 1)
      -> Output [B, 1]
```

其中：

```text
h = n * (n - 1) / 2
n_in = 2 * h + 4 * n
```

默认参数为 `n=15`，因此：

```text
h = 105
n_in = 270
```

# AlphaNet-Attention 模型结构

对应 `models.py` 中的 `AlphaNet_att` 类（第 360-441 行）。

```text
Input X [B, n, T]
|
|- 特征提取分支 1: ts_corr(d, stride)        -> [B, h, w] -> BN(h)
|- 特征提取分支 2: ts_cov(d, stride)         -> [B, h, w] -> BN(h)
|- 特征提取分支 3: ts_stddev(d, stride)      -> [B, n, w] -> BN(n)
|- 特征提取分支 4: ts_zscore(d, stride)      -> [B, n, w] -> BN(n)
|- 特征提取分支 5: ts_return(d, stride)      -> [B, n, w] -> BN(n)
`- 特征提取分支 6: ts_decaylinear(d, stride) -> [B, n, w] -> BN(n)

特征拼接：

    concat(dim=1)
    [B, h, w] + [B, h, w] + 4 * [B, n, w]
    -> [B, n_in, w]

自注意力建模与输出：

    [B, n_in, w]
      -> Transpose(1, 2)
      -> [B, w, n_in]
      -> MultiheadAttention(
           embed_dim=n_in,
           num_heads=3,
           dropout=0.1
         )
      -> [B, w, n_in]
      -> LayerNorm(n_in)
      -> 时间维均值: mean(dim=1)
      -> [B, n_in]
      -> Linear(n_in, 1)
      -> Output [B, 1]
```

其中：

```text
h = n * (n - 1) / 2
n_in = 2 * h + 4 * n
```

默认参数为 `n=15`，因此：

```text
h = 105
n_in = 270
```
