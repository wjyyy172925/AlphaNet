# 数据切分说明

这份说明对应 `构建数据集.ipynb` 里“构建特征图和标签”那段代码。

## 输入

输入是已经整理好的 `df_merged`。

每一行是一只股票在某个交易日的数据，核心字段包括：

- `code`
- `date`
- `open`
- `close`
- `high`
- `low`
- `volumn`
- `vwap`
- `return`
- `turn`
- `target`

其中 `target` 是标签列，通常直接等于 `return`，只是单独起个名字，方便后面把标签从特征里排除掉。

## 切分方式

代码是按“单只股票 + 时间滑窗”来切的。

1. 先按 `code` 遍历每只股票。
2. 对每只股票单独取出它自己的时间序列。
3. 用长度为 30 个交易日的窗口做输入特征。
4. 用第 `i+40` 天的 `target` 作为标签。
5. 每次窗口向前移动 10 个交易日。

也就是：

- 输入窗口：`i ~ i+29`
- 标签日期：`i+40`
- 步长：`10`

这样做的目的，是让样本之间保留一定间隔，避免过于密集地重复取样。

## 输入输出

### 输入 X

这一句：

```python
window = df.iloc[i:i+30, 1:-1]
window.set_index('date', inplace=True)
window = window.transpose()
```

含义是：

- 取连续 30 天的数据
- 去掉 `code` 和最后一列 `target`
- 以 `date` 作为列索引
- 再转置成模型需要的二维图像格式

所以单个样本的形状是：

```text
(特征数, 30)
```

在文档里的这个版本中，特征数是 9，所以单样本是：

```text
(9, 30)
```

最终 `X` 的形状是：

```text
(N, 9, 30)
```

### 输出 Y

这一句：

```python
y.append(df.iloc[i+40]['target'])
```

表示标签是第 `i+40` 天的收益率，也就是未来收益。

最终 `Y` 的形状是：

```text
(N,)
```

### 标签日期 Y_dates

这一句：

```python
date = df.iloc[i+40]['date']
```

保存的是每个标签对应的日期，用来最后按时间排序。

最终 `Y_dates` 的形状是：

```text
(N,)
```

## 代码作用拆解

### `X, Y, Y_dates, empty = [], [], [], []`

初始化四个容器：

- `X`：存所有样本特征
- `Y`：存所有标签
- `Y_dates`：存所有标签日期
- `empty`：存数据不够的股票代码

### `for code in tqdm(df_merged['code'].unique()):`

逐只股票采样。

这样做可以保证：

- 不同股票之间不会混在一起
- 每只股票的时间序列独立切片

### `while i + 40 < len(df):`

控制滑窗范围。

这里要同时满足：

- 前面有 30 天窗口可取
- 后面还能取到第 `i+40` 天作为标签

### `if not x or not y:`

如果某只股票数据太少，直接跳过。

### `x = np.stack(x)` / `y = np.stack(y)`

把 list 变成 numpy 数组，便于后面统一拼接。

### `order = np.argsort(Y_dates)`

按标签日期升序排序。

这样做是为了让整个数据集按时间顺序排列，方便后续训练、验证和回测。

## 最终结果

最终得到三个核心对象：

- `X`：模型输入
- `Y`：回归标签
- `Y_dates`：标签日期

以及一个辅助列表：

- `empty`：数据不足的股票

## 一句话总结

这段代码本质上是在做：

```text
按股票分组
-> 用过去30天构造输入
-> 用第40天收益率做标签
-> 每10天采一次样
-> 最后按日期排序
```

## 后续合并步骤

上面那段代码只是把单只股票的滑窗样本拼成了 `X / Y / Y_dates`，后面还会继续做几步处理。

### `df_merged['target'] = df_merged['return']`

这一步是把收益率单独复制一列出来，作为标签列 `target`。

这样做的好处是后面切窗口时可以直接用最后一列排除标签，而不用担心把 `return` 当成特征混进去。

### 特征标准化

```python
for feature in df_merged.columns[2:-1]:
    df_merged[feature] = (df_merged[feature] - df_merged[feature].mean()) / df_merged[feature].std()
```

这一步是在对输入特征做标准化。

含义是：

- 跳过 `code` 和 `date`
- 跳过最后一列 `target`
- 对中间的所有特征列逐列做 z-score 标准化

这里的 `columns[2:-1]` 实际包含：

- `open`
- `close`
- `high`
- `low`
- `volumn`
- `vwap`
- `return`
- `turn`

### 合并所有股票样本

```python
X.append(x)
Y.append(y)
Y_dates.append(y_dates)
```

每只股票先单独生成一批样本，再统一放进总列表里。

最后用：

```python
Y_dates = np.concatenate(Y_dates, axis=0)
order = np.argsort(Y_dates)
X = np.concatenate(X, axis=0)[order]
Y = np.concatenate(Y, axis=0)[order]
Y_dates = Y_dates[order]
```

把所有股票的样本合并起来，并按标签日期升序排序。

这样得到的全局样本集就是：

- `X`：所有股票的输入样本
- `Y`：所有股票的回归标签
- `Y_dates`：所有样本对应的日期

### 构建分类标签 `Y_cls`

```python
memo = {}
Y_cls = []

for i in tqdm(range(len(Y))):
    date = Y_dates[i]
    if date in memo:
        avg = memo[date]
    else:
        avg = df_merged[df_merged['date']==date]['target'].mean()
        memo[date] = avg
    if Y[i] > avg:
        Y_cls.append(1)
    else:
        Y_cls.append(0)
```

这一步是在把回归问题转成分类问题。

规则很简单：

- 如果某只股票这一天的收益率高于当天市场平均收益率，记为 `1`
- 否则记为 `0`

`memo` 的作用是缓存每天的市场均值，避免同一天反复计算。

### 标准化回归标签

```python
Y_norm = (Y - np.mean(Y)) / np.std(Y)
```

这一步是把回归标签 `Y` 再做一次标准化，得到 `Y_norm`。

所以最后会同时保留：

- `Y`：原始回归收益率
- `Y_norm`：标准化后的回归收益率
- `Y_cls`：分类标签

### 保存结果

```python
np.save('X_fe.npy', X)
np.save('Y_fe_cls.npy', Y_cls)
np.save('Y_fe_norm.npy', Y_norm)
np.save('Y_dates.npy', Y_dates)
```

这一步是把最终数据集存到本地，供训练框架直接读取。

对应关系是：

- `X_fe.npy`：特征输入
- `Y_fe_cls.npy`：分类标签
- `Y_fe_norm.npy`：标准化回归标签
- `Y_dates.npy`：标签日期
