# 数据集文件说明

构建数据集后，Notebook 使用 `np.save` 将输入特征、标签和标签日期保存为 `.npy` 文件：

```python
np.save('X_fe.npy', X)
np.save('Y_fe_cls.npy', Y_cls)
np.save('Y_fe_norm.npy', Y_norm)
np.save('Y_dates.npy', Y_dates)
```

## 1. `X_fe.npy`

保存模型输入特征。

```text
维度: [N, 8, 30]
```

根据 Notebook 中的输出：

```text
X.shape = (21313, 8, 30)
```

各维度含义：

```text
N = 21313: 样本数量
8:         每个样本包含的特征数量
30:        每个特征包含的历史时间点数量
```

单个样本的形状为：

```text
X[k].shape = [8, 30]
```

也就是：

```text
第 k 个样本 = 8 个特征 × 30 个历史时间点
```

## 2. `Y_fe_cls.npy`

保存分类任务的标签。

```text
维度: [N]
取值: 0 或 1
```

标签含义：

```text
Y_cls[k] = 1:
第 k 个样本的收益率超过当天市场平均收益率

Y_cls[k] = 0:
第 k 个样本的收益率没有超过当天市场平均收益率
```

它用于分类任务：

```text
X[k] -> 预测 0 或 1
```

## 3. `Y_fe_norm.npy`

保存标准化后的连续收益率标签。

```text
维度: [N]
```

计算方式：

```python
Y_norm = (Y - np.mean(Y)) / np.std(Y)
```

其中 `Y_norm[k]` 表示第 `k` 个样本未来收益率的标准化结果。

它用于回归任务：

```text
X[k] -> 预测一个连续收益率
```

标准化后通常满足：

```text
均值约等于 0
标准差约等于 1
```

## 4. `Y_dates.npy`

保存每个标签对应的目标日期。

```text
维度: [N]
```

例如：

```text
Y_dates[k] = 2015-06-18
```

表示：

```text
X[k] 使用目标日期之前的 30 个时间点作为输入，
Y[k] 或 Y_cls[k] 对应 2015-06-18 这一天的标签。
```

因此，`Y_dates` 保存的是标签日期，而不是输入窗口中最后一个时间点的日期。

## 5. 四个数组的对应关系

理想情况下，四个数组应当按相同的样本索引一一对应：

```text
X_fe[k]       -> 第 k 个输入样本
Y_fe_cls[k]   -> 第 k 个分类标签
Y_fe_norm[k]  -> 第 k 个回归标签
Y_dates[k]    -> 第 k 个样本的目标日期
```

因此需要满足：

```python
len(X) == len(Y_cls) == len(Y_norm) == len(Y_dates)
```

## 6. 当前 Notebook 中的维度问题

Notebook 当前记录的输出为：

```text
X.shape     = (21313, 8, 30)
Y.shape     = (21313,)
Y_cls.shape = (105637,)
```

这里 `X` 的样本数是 `21313`，但 `Y_cls` 的长度是 `105637`，两者不一致。

可能原因包括：

```text
1. Notebook 单元格执行顺序混乱
2. 变量 X 或 Y 被重新赋值
3. Notebook 中保存的输出结果不是同一次运行产生的
```

保存数据前建议检查：

```python
print('X:', X.shape)
print('Y_cls:', Y_cls.shape)
print('Y_norm:', Y_norm.shape)
print('Y_dates:', Y_dates.shape)

assert len(X) == len(Y_cls) == len(Y_norm) == len(Y_dates)
```

只有四个数组的样本数量一致时，才能保证输入样本和标签正确对应。
